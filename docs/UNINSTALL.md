# Removing Filter Curve Digitizer

The current application is portable and does not require a system installer.

- **Windows:** close the application and delete the downloaded EXE and any copies you made.
- **macOS:** close it and remove `Filter Curve Digitizer.app` and the downloaded archive.
- **Linux:** close it and delete the AppImage.
- **Python source:** close it and delete the extracted project directory, including the project-specific `.venv` if you created one using our instructions. Do not remove a shared Python installation or packages used by other programs.

To remove saved preferences, delete `.filter-curve-digitizer` in your home directory. On Windows this is normally `%USERPROFILE%\.filter-curve-digitizer`; on macOS/Linux, `~/.filter-curve-digitizer`.

User-created images, overlays, CSV and JSON files remain where you saved them. Downloaded update packages remain in Downloads until you delete them. Removing the application does not remove filters already imported into PixInsight or Siril.
